# ADR-013: Smart Default Moving Averages Strategy

## Status
Accepted

## Date
2026-07-31

## Context
프론트엔드 차트 뷰어에서 1분~60분봉과 1일~1월봉 간 타임프레임(Timeframe)을 동적으로 전환할 때, 모든 이동평균선(Moving Averages)이 일률적으로 켜져 있거나 고정되어 있으면 차트가 시각적으로 왜곡되고 가독성이 크게 떨어지는 문제가 발생했습니다. 예를 들어 분봉 차트에서 장기 일봉 이평선(120일선 등)이 켜져 있을 경우 Y축 스케일이 망가지는 현상이 존재했습니다.
이에 따라 이동평균선의 주기를 표준화하고, 사용자가 직접 끄고 켜지 않아도 타임프레임에 맞게 자동으로 최적의 이평선이 표시되는 UX(스마트 디폴트)가 필요해졌습니다.

## Decision
1. **이평선(MA) 주기 표준화**:
   - 단기(분봉) 이평선: `5m, 10m, 20m, 60m, 120m` (디버깅용 `1m`)
   - 장기(일봉) 이평선: `5d, 20d, 60d, 120d` (디버깅용 `1d`)
   - 백엔드의 SQLite 윈도우 함수를 상기 주기에 맞게 재구성(`ROWS BETWEEN n PRECEDING`).
2. **Smart Defaults 도입**:
   - 강제 제약(Systematic restriction) 대신 스마트 디폴트를 적용합니다. 
   - 프론트엔드(`ChartContainer.tsx`)에서 타임프레임 전환 시, 해당 타임프레임 성격에 맞지 않는 이평선들은 자동으로 `Off` 되고, 맞는 이평선들은 자동으로 `On` 되도록 상태(`visibleMAs`)를 즉시 업데이트(Overwriting)합니다.
   - 단, 사용자가 체크박스를 통해 임의의 이평선을 켜고 끄는 행위 자체를 원천 차단하지는 않습니다(강제 오버라이딩 가능).

## Consequences
- **UX 향상**: 사용자는 번거롭게 범례(Legend)를 조작할 필요 없이 최적화된 차트 뷰를 경험할 수 있습니다.
- **백/프론트 동기화**: 백엔드와 프론트엔드의 `ChartDataPoint` 타입이 새로 정의된 표준에 맞춰 강력하게 동기화되었습니다.
- **확장성 제약**: 커스텀 이평선(예: 33일선)을 사용자가 직접 입력하는 기능은 현재 지원하지 않으며, 미리 지정된(Preset) 표준 이평선에 대해서만 렌더링이 이루어집니다.
