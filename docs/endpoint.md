# 인터페이스 및 엔드포인트 상세 명세서 (API & Endpoint Specs)

본 문서는 FastAPI 프레임워크를 기반으로 구축된 내부 관리용 API 및 외부 클라이언트 호출용(Market) 인터페이스 구조를 정의합니다. KIS OpenAPI와의 통신 결과를 표준화하고, 로컬 DB의 데이터 무결성을 검증하는 데 주 목적이 있습니다.

---

## 1. 통신 객체 래핑 (APIResp Wrapper)

KIS OpenAPI의 JSON 응답은 깊이가 깊고 파편화되어 있습니다. 이를 내부에서 다루기 쉽도록 `APIResp` 객체와 내부 `DotDict` 헬퍼 클래스를 도입하여 점 표기법(Dot-notation)으로 접근할 수 있도록 래핑(Wrapping)합니다.

- **독립성 유지**: `TR_ID`나 엔드포인트 URL 경로 등 API 호출에 필요한 메타 정보는 `app/core/` 하단의 거대한 전역 딕셔너리에 모아두지 않고, **해당 API를 호출하는 서비스 로직이나 라우터 함수 내부에 직접 명시**합니다. 이는 코드를 읽을 때 파편화를 방지하고 결합도를 낮추기 위함입니다.

---

## 2. 관리자 검증 라우터 (`/admin`)
**파일 위치:** `app/routes/admin.py`

배치 스케줄러가 백그라운드에서 적재한 데이터가 100% 무결한지(누락, 빵꾸, 동기화 지연 등이 없는지) 관리자가 수동으로 즉시 확인할 수 있는 검증용 엔드포인트입니다.

### 2-A. 전체 데이터 보유량 검증 (`/admin/{daily|minute}/check`)
- **작동 원리**: 
  - `stock_codes` 테이블에 존재하는 살아있는(Active) 2,400여 개 전 종목 명단을 기준(Target)으로 삼습니다.
  - 해당 종목들이 `daily_ohlcv` 또는 `minute_ohlcv` 테이블에서 **'최신 영업일 기준'**으로 누락 없이 데이터가 적재되어 있는지 검증합니다.
- **일봉 특화 검증**:
  - 일봉의 경우, 단순히 최신 날짜만 확인하는 것이 아니라 각 종목별로 과거 최소 400일(또는 상장일 기준 그 이상)의 시계열 데이터가 90% 이상의 보유율을 충족하고 있는지를 듀얼로 검증하여 리포트합니다.

### 2-B. Spot-Check 무결성 검증 (`/admin/{daily|minute}/verify`)
- **작동 원리**:
  - 보유율 100%가 나오더라도 실제 값(시/고/저/종/거래량)이 맞는지 확신할 수 없으므로, 무작위로 소수의 종목(Spot Check)을 추출합니다.
  - KIS API에 실시간으로 데이터를 요청하고, 로컬 SQLite에 저장된 동일 시간대/날짜의 데이터와 1:1로 초고속 비교(Diff)합니다.
- **상세 누락 감지 (Gap Detection)**:
  - API가 반환한 캔들이 DB에 없는 경우 단순 개수만 세지 않고, `missing_dates: ["YYYYMMDD", ...]` 배열에 실제 누락 일자를 기록하여 향후 Admin UI 연동 시 직관적으로 파악할 수 있게 돕습니다. (휴장일은 자연스레 제외됨)
- **분봉 검증 시 노이즈 방어 로직**:
  - 장중(09:00 ~ 15:30)에 분봉 데이터를 실시간 검증할 경우, API 응답과 DB 기록 간 미세한 초 단위 지연(Delay)으로 인해 마지막 캔들의 값이 다르게 보일 수 있습니다 (False Alarm).
  - 이를 방지하기 위해 분봉 테스터는 항상 **"DB에 적재된 가장 최신 캔들의 시간"**을 기준으로 잡아, 해당 과거 시간 캔들을 API와 비교함으로써 실시간 통신 노이즈를 완벽하게 회피합니다.

## 3. 퍼블릭 마켓 라우터 (`/market`)
**파일 위치:** `app/routes/market.py`

프론트엔드 대시보드(Next.js 예정) 혹은 내부 트레이딩 봇이 판단을 내리기 위해 호출하는 API입니다.

### 주요 기능 (개발 예정)
- **Zero-Latency 시세 조회**: KIS 서버를 거치지 않고 오직 `trading.db`에서만 데이터를 즉시 꺼내와 반환합니다.
- **Hotlist (돌파 후보군) 조회**: 당일 거래대금 폭발, 기관/외인 수급 상위 종목, 단기 이동평균선 돌파 등 특정 조건을 만족하는 종목 리스트를 즉각적으로 쿼리하여 응답합니다.
